# Requirement

Application: OrangeHRM Login Module

User Story:

As an administrator, I want to log in using valid credentials so that I can access the dashboard and manage employee information.

Acceptance Criteria

1. User can log in with valid credentials.
2. User is redirected to Dashboard after successful login.
3. Invalid credentials display an error message.
4. Empty username or password is not accepted.
5. Only authorised users can access the Dashboard.
